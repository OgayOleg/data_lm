# Данные проекта

> Датасеты **не хранятся в git** (см. `.gitignore`). Скачиваются одной командой:
> `make data` или `python -m src.download` — с обязательной проверкой SHA-256.

## 1. Telco Customer Churn — `data/raw/telco_customer_churn.csv`

| Параметр | Значение |
|---|---|
| Kaggle | https://www.kaggle.com/datasets/blastchar/telco-customer-churn |
| Первоисточник | IBM Sample Data Sets |
| Записей | 7 043 |
| Признаков | 20 (+ ID-колонка) |
| Целевая переменная | `Churn` (Yes/No → 1/0) |
| Дисбаланс | 73.5% / 26.5% |
| SHA-256 | `16320c9c1ec72448db59aa0a26a0b95401046bef5d02fd3aeb906448e3055e91` |

**Особенности:** 11 пустых значений `TotalCharges` (клиенты с `tenure = 0`),
смешанные типы (числовые + категориальные), мультиколлинеарность
`TotalCharges ≈ tenure × MonthlyCharges`.

`unknown` в 6 признаках; 5 макроэкономических признаков, сильно коррелирующих
между собой.

## Откуда скачиваются файлы

Поскольку в среде выполнения проекта прямой доступ к kaggle.com отсутствует,
скрипт `src/download.py` загружает **побайтово идентичные публичные зеркала**
этих датасетов с GitHub и проверяет контрольные суммы. Зеркала закреплены на
конкретных коммитах (URL с `?ref=<commit-sha>`), поэтому результат скачивания
воспроизводим во времени.

Если вы запускаете проект у себя и у вас есть доступ к Kaggle — просто положите
оригинальные CSV-файлы в `data/raw/` под именами из таблиц выше и запустите
`make pipeline`: контрольные суммы должны совпасть.

## Структура каталогов

```
data/
├── raw/        # исходные CSV (скачиваются, в git не хранятся)
├── interim/    # промежуточные выгрузки (в git не хранятся)
└── processed/  # подготовленные матрицы признаков (в git не хранятся)
reports/
├── figures/    # все графики пайплайна (в git хранятся)
└── metrics/    # таблицы метрик, JSON-сводки (в git хранятся)
models/         # обученные модели (.joblib, в git не хранятся)
```
